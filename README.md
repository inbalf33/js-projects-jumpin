# js-projects-jumpin

#### משחק הזיכרון 1 ####

משחק זיכרון אינטראקטיבי ל-2 שפותח באמצעות HTML, CSS, Bootstrap ו-JavaScript .

## תיאור הפרויקט
המשחק מציע תחרות בין 2 השחקנים, כל שחקן בתורו הופך 2 קלפים ומנסה למצוא זוגות תואמים.
המשחק כולל מעקב בזמן אחרי הניקוד, כמות הניסיונות ומאזן ניצחונות מצטבר לאורך כמה סיבובים.

## פונקציונליות עיקרית
- **מסך הרשמה והגדרות:** אפשרות להזנת שמות השחקנים ובחירת רמת קושי (קל, בינוני, קשה) המשפיעה על גודל הלוח וכמות הזוגות.
- **מנגנון משחק ותורים:** ניהול תורים דינמי כולל חיווי ויזואלי בולט לשחקן הפעיל (שינוי צבעים ומסגרות).
- **לוגיקת השוואת קלפים:** בדיקה מקבילית של זוגות, נעילת הלוח בזמן השהייה למניעת לחיצות כפולות, ושמירת קלפים גלויים במידה שנמצאה התאמה.
- **טיימר ומעקב בזמן אמת:** מדידת זמן המשחק, ספירת ניסיונות לכל שחקן וספירת זוגות שנמצאו.
- **סיום משחק ומודאל ניצחון:** זיהוי סיום המשחק, הצגת חלון קופץ עם תוצאת הסיבוב, מעקב ניצחונות סדרתי ואפשרות להתחיל סיבוב נוסף או לחזור להגדרות.
- **איפוס דינמי:** אפשרות לאיפוס הסיבוב בכל רגע באמצעות כפתור ייעודי עם התראה מתאימה.

## איך מפעילים את המשחק?
1. מורידים את קבצי הפרויקט (או משכפלים את ה-Repository).
2. פותחים את הקובץ `index.html` בכל דפדפן .
3. מזינים את שמות השחקנים, בוחרים רמת קושי ולוחצים על "התחל משחק".
