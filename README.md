# js-projects-jumpin

## פרויקט 1 - משחק הזיכרון ##

משחק זיכרון אינטראקטיבי ל-2 שפותח באמצעות HTML, CSS, Bootstrap ו-JavaScript .

### תיאור הפרויקט
המשחק מציע תחרות בין 2 השחקנים, כל שחקן בתורו הופך 2 קלפים ומנסה למצוא זוגות תואמים.
המשחק כולל מעקב בזמן אחרי הניקוד, כמות הניסיונות ומאזן ניצחונות מצטבר לאורך כמה סיבובים.

### פונקציונליות עיקרית
- **מסך הרשמה והגדרות:** אפשרות להזנת שמות השחקנים ובחירת רמת קושי (קל, בינוני, קשה) המשפיעה על גודל הלוח וכמות הזוגות.
- **מנגנון משחק ותורים:** ניהול תורים דינמי כולל חיווי ויזואלי בולט לשחקן הפעיל (שינוי צבעים ומסגרות).
- **לוגיקת השוואת קלפים:** בדיקה מקבילית של זוגות, נעילת הלוח בזמן השהייה למניעת לחיצות כפולות, ושמירת קלפים גלויים במידה שנמצאה התאמה.
- **טיימר ומעקב בזמן אמת:** מדידת זמן המשחק, ספירת ניסיונות לכל שחקן וספירת זוגות שנמצאו.
- **סיום משחק ומודאל ניצחון:** זיהוי סיום המשחק, הצגת חלון קופץ עם תוצאת הסיבוב, מעקב ניצחונות סדרתי ואפשרות להתחיל סיבוב נוסף או לחזור להגדרות.
- **איפוס דינמי:** אפשרות לאיפוס הסיבוב בכל רגע באמצעות כפתור ייעודי עם התראה מתאימה.

### איך מפעילים את המשחק?
1. מורידים את קבצי הפרויקט (או משכפלים את ה-Repository).
2. פותחים את הקובץ `index.html` בכל דפדפן .
3. מזינים את שמות השחקנים, בוחרים רמת קושי ולוחצים על "התחל משחק".




## פרויקט 2 - בונה מסכים ##

כלי דינמי לבניית טפסים ועמודים בשיטת Visual Builder, שפותח באמצעות HTML, CSS, Bootstrap ו-JavaScript.

### תיאור הפרויקט
האפליקציה מאפשרת למשתמש לעצב ולבנות ממשק ויזואלי בזמן אמת. המשתמש בוחר סוגי אלמנטים שונים, מגדיר את התוכן והמאפיינים העיצוביים שלהם, ומציג אותם על גבי קנבס אינטראקטיבי בזמן אמת.

### פונקציונליות עיקרית
- **סרגל כלים והוספת אלמנטים:** תמיכה במגוון סוגי אלמנטים (כותרות, פסקאות, כפתורים, שדות קלט ותמונות) עם התאמת שדות הקלט באופן דינמי לסוג האלמנט שנבחר.
- **התאמה עיצובית מותאמת אישית:** שליטה מלאה במאפיינים עיצוביים כולל רוחב, גובה, מרווחים (margins), צבעי טקסט ורקע, גודל פונט, יישור טקסט וסגנונות (בולד / קו תחתון).
- **קנבס דינמי וייצוג ב-DOM:** הוספת אלמנטים בלייב ללא כתיבת קוד, כולל טיפול במצב קנבס ריק (Empty State).
- **בחירת אלמנטים והדגשה ויזואלית:** מנגנון לחיצה לבחירת אלמנט בקנבס, הכולל מסגרת הדגשה צהובה מדויקת.
- **מחיקת אלמנטים:** כפתור פח אשפה צף המופיע ברחיפה או בבחירת אלמנט ומאפשר הסרה מהירה של האלמנט מהקנבס.
- **שמירה מקומית (LocalStorage):** שמירה אוטומטית של מצב הקנבס כך שהנתונים נשמרים גם לאחר רענון הדפדפן.
- **איפוס מלא:** כפתור איפוס המנקה את הקנבס ומאפס את ה-LocalStorage בלחיצה אחת.
- **ולדיציה ובדיקת קלט:** מנגנון אימות בסיסי למניעת יצירת אלמנטים ללא מידע הכרחי.

### איך מפעילים את הפרויקט?
1. מורידים את קבצי הפרויקט (או משכפלים את ה-Repository).
2. פותחים את הקובץ `index.html` בכל דפדפן.
3. בוחרים אלמנט מתוך סרגל הכלים בצד, מגדירים את העיצוב והתוכן, ולוחצים על "הוסף אלמנט".




## פרויקט 3 - אפליקציית חיפוש סרטים ##

אפליקציה אינטראקטיבית לחיפוש סרטים וסדרות מול API חיצוני, שפותחה באמצעות HTML, CSS, Bootstrap ו-JavaScript (Axios).

### תיאור הפרויקט
האפליקציה מתחברת ל-API של OMDB ומאפשרת למשתמשים לחפש סרטים וסדרות בזמן אמת, לסנן את התוצאות, ולצפות בפרטים מלאים על כל סרט בתוך כרטיסייה אינטראקטיבית.

### פונקציונליות עיקרית
- **חיפוש בזמן אמת:** שליפת תוצאות חיפוש מול OMDB API לפי שם הסרט או הסדרה.
- **סינון תוצאות:** אפשרות לסינון לפי סוג התוכן (סרטים / סדרות) ולפי שנת יציאה מדויקת.
- **איפוס סינונים:** כפתור "נקה סינון" המאפס את שדות הסינון ומחזיר אוטומטית את תוצאות החיפוש המקוריות.
- **תצוגת פרטים מורחבת (Overlay):** לחיצה על "פרטים נוספים" טוענת בלייב ומציגה תקציר עלילה, ז'אנר, במאי, שחקנים ודירוג IMDb בתוך הffכרטיסייה.
- **חוויית משתמש וטיפול בשגיאות:** הצגת אינדיקטור טעינה (Spinner), הודעות שגיאה מותאמות למצבים בהם לא נמצאו תוצאות, ותמונת ברירת מחדל (Placeholder) למקרים בהם הפוסטר חסר.
- **ניקוי ממשק דינמי:** הסרת הודעות שגיאה אוטומטית בעת שינוי טקסט החיפוש ואיפוס התצוגה בעת מחיקת הקלט.

### איך מפעילים את הפרויקט?
1. מורידים את קבצי הפרויקט (או משכפלים את ה-Repository).
2. פותחים את הקובץ `index.html` בכל דפדפן.
3. מקלידים שם של סרט או סדרה בשורת החיפוש ולוחצים על "חפש".
* **מפתח API:** הפרויקט כולל מפתח מובנה (`API_KEY`) לצורך בדיקה מהירה. במידת הצורך, ניתן להחליף את המפתח בקובץ `script.js`.
